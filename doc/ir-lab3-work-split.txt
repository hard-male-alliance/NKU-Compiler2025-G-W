3. Shared contracts
-------------------
- One scalar element Type, a distinct tensor type category, and an ordered
  shape. A negative first extent denotes an unsized parameter; subsequent
  extents are positive constants for tensors.
- A fully indexed tensor is a scalar; a bare tensor supplies an aggregate
  buffer. Ordinary arrays keep partial indexing and the existing runtime ABI.
- VarDeclarator.binding and initializers are the only sources of declaration
  layout for codegen. The plan records explicit elements in source order;
  omitted elements are zero only when an initializer requires zero fill.
- ExprNode attributes carry scalar type/constant value and aggregate shape;
  extentParameter names the actual argument supplying a dynamic first
  extent. Function return metadata publishes either a fixed shape or that
  first-extent dependency. B consumes the annotations without recomputing
  semantic rules.
- A tensor argument passes pointer plus the first extent. Return storage
  belongs to the caller. Static shape conflicts fail in semantic analysis;
  operations with unknown extents compare their runtime lengths before use.
- Lab1/Lab2 fixture output and the classroom testcase tree and test.py
  are preserved. New negative cases check diagnostics, not just parser failure.
