  Owns parser semantic types, expression productions and array indexing;

Person B -- declaration/control-flow grammar, AST printing, CLI integration

Both people have substantive grammar work. Neither is assigned only testing

a commit integrator assembles the indicated contributions without claiming
that the other person's work was independently authored by the integrator.

3. Shared contracts agreed before editing
----------------------------------------
- Every owning node semantic value is unique_ptr<NodeType>.
- ParserList<T> owns a vector and its elements until an AST constructor takes
  the whole list. Moves transfer semantic values; release() transfers a child
  into the existing raw-pointer AST constructors. Entry* and Type* are shared.
- TYPE -> INT | FLOAT | VOID remains shared across the existing framework.
- NOCOMMA_EXPR separates commas in argument/initializer/declaration lists;
  EXPR retains the framework's comma-expression extension.
- ARRAY_DIMENSION_EXPR_LIST is nonempty. A plain name has a null indices list;
  an unsized first parameter dimension is a LiteralExpr(-1).
- B's statements consume A's EXPR and LEFT_VAL_EXPR. A's expression rules
  do not construct statements or change statement/declaration productions.
- Every braced block is a BlockStmt, even when empty or single-item.
- PROGRAM publishes the root only after END. Syntax/lexical failure must
  return a nonzero CLI exit code and no partial AST.
- Preserve existing token names, runtime timing-call lowering, sized first
  parameter dimensions in the supplied fixture, and all three AST goldens.

Only A edits the semantic declaration block. B supplies production bodies
using the agreed semantic types. Only B edits printer and CMake registration.
For shared test-file integration, B owns the harness and main(); A supplies
expression helper/property functions. This avoids simultaneous edits to the
same lines without splitting the grammar into artificial source modules.

  after reviewing those exact diffs. Never use git add . or git commit -a.

  main() changes; stage that delta together with B14 for C4.

  git diff --cached. Confirm no future-commit files/functions are included.
- For an intermediate-commit build, materialize the proposed index tree under
  .temp/lab2, with its own build directory. A build of the completed working tree
  alone does not demonstrate that the staged intermediate tree builds.
  Use a typed Python helper if automating index snapshots or test orchestration.
